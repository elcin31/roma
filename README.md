# ROMA

Цифровой музей Римского мира. Русскоязычное статическое издание на Astro с подлинными музейными фотографиями, связанной исторической моделью и интерактивным атласом MapLibre.

Работающий сайт: **https://roma-coral.vercel.app**.

Единственный репозиторий: https://github.com/elcin31/roma. Ветка production: `main`.
Vercel: scope `elcin31s-projects`, проект `roma` (`prj_oaL79Qwd8N02Zjl2A3q0Aect8t2Z`).

## Начальная редакция

- 6 больших исследований, каждое около 900–1 000 слов.
- 13 кратких биографических очерков; 1 династическая запись.
- 28 событий и отдельная страница осады Алезии.
- 5 страниц эпох; 11 городов и поселений Pleiades.
- 8 предметов The Met Open Access с индивидуально проверенными правами.
- 24 записи первоисточников и исследований; 3 описания наборов геоданных.
- 3 политических среза AWMC: 60 до н. э., 117 и 200 н. э.

Это опубликованный начальный корпус, а не выполнение всего редакционного плана на 25+ исследований и 40+ биографий. Границы провинций представлены линиями без вымышленных названий. Itiner-e не импортирован. Редакционная сверка не равнозначна независимому научному рецензированию.

## Локальный запуск

Node.js 22.12+ (production/CI: Node 24).

```sh
npm ci
npm run dev
```

Поиск Pagefind появляется после production-сборки:

```sh
npm run build
npm run preview -- --port 4321
```

```sh
npm run check
npm run test:unit
npx playwright install --with-deps chromium webkit
npm test
```

В окружении без WebKit можно выполнить `npx playwright test --project=chromium --project=mobile-chromium`. Это не является проверкой Safari. `ROMA_TEST_URL` позволяет направить браузерные тесты на развёрнутый сайт. `ROMA_WEBKIT_EXECUTABLE` — необязательный путь к локальному запускателю WebKit для окружений без системной установки библиотек.

## Архитектура

- `src/lib/schema.ts`: строгие типы и Zod-схемы исторических сущностей и дат.
- `src/data/catalog.json`: единый граф сущностей со стабильными ID, статусами и основаниями сверки.
- `src/content/articles/*.mdx`: длинные статьи; Astro Content Collections проверяет frontmatter.
- `src/lib/catalog.ts`: единый фильтр публикации (`verified` + review), выборки и обратные связи.
- `src/pages/`: статические страницы разделов, сущностей и исследований.
- `src/components/Atlas.tsx`: единственный React-остров; MapLibre загружается динамически.
- `public/geo/`: локальные GeoJSON, лицензия ODbL, манифест версий и контрольных сумм.
- `src/data/museum-records.json`: снимок индивидуальных каталожных записей Met.
- `src/data/place-provenance.json`: авторы и исходные записи Pleiades.
- `src/styles/`: собственные токены и композиции; локальные Literata и Manrope с кириллицей.
- `scripts/validate.ts`: целостность ссылок, контент, даты, музейные права и геометрия.
- `scripts/check-links.mjs`: все локальные ссылки, изображения и якоря production HTML.
- `tests/`: реальные браузерные сценарии и проверки исторической хронологии.

Сервер, база данных, CMS, регистрация и платные API не используются. Pagefind работает в браузере; закладки сохраняются в localStorage с обработкой отказа и повреждённых данных. Статьи и каталоги доступны без JavaScript. Карта и поиск требуют JavaScript.

## Атлас

Подложка Natural Earth 1:110m размещена локально; публичных тайловых CDN нет. Исторический слой грузится только для выбранного среза. При переключении старая геометрия удаляется до загрузки новой, чтобы подпись даты не относилась к чужому слою. Дороги и провинциальные линии загружаются по запросу. Операции отменяются при смене состояния; MapLibre и маркеры освобождаются при размонтировании.

Слой дорог AWMC отражает широкую датировку. Военный режим показывает связанные с событиями места, включая Алезию, но не вымышленные маршруты и не точные позиции войск. Культурный режим выделяет города и археологические комплексы; это пока не подробный каталог отдельных построек. Городские координаты — `reprPoint` Pleiades. Современная береговая линия не объявляется античной.

## Публикация

Vercel связан с `elcin31/roma`, production branch `main`. `npm run build` включает typecheck, валидацию, генерацию HTML, индекс Pagefind и проверку ссылок. Каталог публикации — `dist`; адаптер сервера не нужен. GitHub Actions проверяет сборку, данные и Chromium desktop/mobile. Не требуются переменные окружения или секреты приложения.

При повторном импорте использовать существующий проект `roma` в `elcin31s-projects`; не создавать дубликат. Фреймворк Astro, install `npm ci`, build `npm run build`, output `dist`, Node 24.

## Данные и редактура

См. [модель и правила редактирования](docs/content.md), [редакционный план](docs/editorial-plan.md), [проверку источников](docs/source-review.md), [лицензии](docs/licenses.md) и [отчёт проверки](docs/verification.md).

Обновление закреплённых AWMC/Met данных: `python scripts/import-data.py`. Команда не изменяет редакционные тексты и не публикует автоматически новые сущности. Для изображений: `node scripts/prepare-images.mjs`. Для Pleiades: `python scripts/import-places.py` использует только уже одобренные ID каталога и сохраняет сведения об авторах. После любого обновления повторить `npm run build` и проверить изменения лицензий/атрибуций.
