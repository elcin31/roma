# Проверка начальной редакции

Дата: 22 октября 2026 года. Проверена production-сборка на Node 24.

## Автоматические проверки

- `astro check`: 0 ошибок TypeScript/Astro.
- `scripts/validate.ts`: 100 опубликованных сущностей, 6 MDX-исследований, 8 записей музейных прав, 7 GeoJSON. Проверяются стабильные ID, публичные связи, даты без нулевого года, координаты, обязательные поля, происхождение данных и изображения.
- `npm run test:unit`: 2 проверки хронологии прошли.
- `npm run build`: 121 HTML-страница; Pagefind индексирует 100 сущностей на русском; 4 249 внутренних ссылок, ресурсов и якорей проверены.
- Полный Playwright: **30 passed, 15 skipped, 0 failed**. Пропуски намеренные: мобильное меню не тестируется на desktop; одинаковая матрица ширин выполняется один раз в Chromium, а не повторяется в остальных проектах.

## Браузеры и реальные сценарии

Chromium desktop, Chromium с мобильным viewport и WebKit с эмуляцией iPhone. WebKit запускался с локально извлечёнными библиотеками WPE; это браузерный движок, а не физический iPhone и не вся среда Safari. GitHub Actions запускает Chromium desktop/mobile; WebKit проверен в рабочем окружении отдельно.

Проверены переходы главная → эпоха → исследование → биография → город → атлас; русский и латинский поиск с фильтрацией и пустым результатом; сохранение, перезагрузка, открытие и удаление закладок; очистка и запрет localStorage; фильтрация коллекции, увеличение фотографии и возврат фокуса; смена реальной картографической геометрии, масштабирование, включение слоёв и отложенная загрузка дорог; отказ загрузки геоданных и повтор; мобильная навигация и Escape.

Ширины **320, 375, 390, 430, 768, 1024, 1440 px**: проверены девять основных страниц, отсутствие горизонтального переполнения и выходящих за экран заголовков. Отдельно просмотрены скриншоты главной и атласа на desktop/mobile.

## Практические пределы

Проверка ссылок относится к внутренним маршрутам и ресурсам. Доступность всех внешних архивов не гарантируется; фактически прочитанные источники и отказы доступа описаны в [source-review.md](source-review.md). Автоматическая валидация не устанавливает историческую истинность текста. Независимое научное рецензирование ещё не проведено.

Физические iOS/Android-устройства, старые браузеры, экранные дикторы и нагрузочное тестирование не проверялись. Показатели Lighthouse/Core Web Vitals не измерялись. Картографические данные пригодны для обзорного изучения, а не для археологической геодезии.
